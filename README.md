EMBER is a visual dashboard displaying how wildfires and water utilities interact through geospatial and economic data. 

**Uploading case studies**

To add a new case study to the dropdown menu, follow these steps:
1. Click on "Admin" in the bottom right corner and enter the password
2. Go to the "Case study costs" tab and upload a CSV.
   If the utility is already in the dropdown, choose it there.
   If it is not on file, select "Enter coordinates (utility not on file)" and
   provide a name, state, latitude, and longitude so EMBER can place a point
   on the map.
